# stacki

Apps for [Stacki](https://stacki.com).

| App | What it does |
|---|---|
| [`cloudflare-analytics`](cloudflare-analytics) | Cloudflare traffic in Stacki: pageviews and visits, AI crawlers, bots vs humans, referrers, top pages, comparison with the previous period. |

Each app lives in its own folder. Tokens and IDs are entered in the app's settings and are never stored in this repository.
