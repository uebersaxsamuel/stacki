# stacki

Apps for [Stacki](https://stacki.com).

| App | What it does |
|---|---|
| [`cloudflare-analytics`](cloudflare-analytics) | See which AI crawlers (ChatGPT, Claude, Perplexity, …) read your site, with pageviews, visits, human vs AI share, referrers and top pages, each compared with the previous period. |

Each app lives in its own folder. Tokens and IDs are entered in the app's settings and are never stored in this repository.
